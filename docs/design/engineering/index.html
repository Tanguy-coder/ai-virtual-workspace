Reading guide
  1. Budget per task, cache share visible (T8).
  2. Every step persisted: tool, time, tokens. Live line = model call running.
  3. Criteria are ticked only with evidence (a test, a run).
  4. Only the validation engine closes a task.
  5. Changes by task or by agent; your edits on your own branch.
  6. Sandbox terminal, read only, real resources.
  7. Checks run on the merge result, not on the branch alone.
  8. Merge into main needs your approval by default.
  9. One branch per task.
  10. Conflicts found on rebase, before merge; nothing overwritten.
  11. Tests run by the platform; the agent reads only failures.
